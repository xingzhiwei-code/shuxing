# 数形 (shuxing) · Roadmap

> 中文交互式数学可视化：从初中到数学前沿，成体系、系列化，开源。
> 灵感来源：3Blue1Brown 的系列化数学可视化。
> 当前阶段：S1 规划中（2026-10-06）

---

## 1. 愿景

把从初中到数学前沿的知识，做成**成体系、系列化**的中文交互式可视化。
不是零散的 demo，而是一部可以"追更"的可视化数学百科，开源给所有人。

## 2. 北极星指标（双）

| 指标 | 含义 | 服务对象 |
|---|---|---|
| 真实使用 | 老师/学生/家长真实在用（UV、分享、进课堂） | 好用 |
| 开源影响力 | GitHub star、contributor 数、社区讨论 | 影响力 |

两者互相咬合：真实使用带来口碑和 star，star 带来更多使用者。
初中/高中阶段侧重"真实使用"，大学及以上阶段侧重"影响力"。

## 3. 内容迭代路径

生产顺序（先锋利再补全）与对外呈现（始终讲"完整体系"）分开。

| 系列 | 学段 | 内容 | 战略作用 | 状态 |
|---|---|---|---|---|
| S1 先锋季 | 初中全体系 | S1a 函数 → S1b 几何 → S1c 代数 → S1d 统计概率（子系列见下） | 验证模式，最锋利的 demo | 规划中 |
| S2 | 高中 | 三角函数、数列、导数入门、概率统计 | 高考流量 | 待启动 |
| S3 | 大学 | 高数（极限/微积分）、线代、概率论 | 大学生自学刚需 | 待启动 |
| S4 | 研究生/博士 | 实分析、泛函、代数拓扑等 | 极客人群，star 来源 | 待启动 |
| S5 旗舰 | 数学前沿 | 千禧难题等科普向可视化 | 品牌制高点，圈内传播 | 待启动 |
| S6 | 小学 | 分数、几何启蒙 | 形态差异大，单独处理，优先级最低 | 待启动 |

**S1 切入点**：初中函数。"拖参数看图像"——拖 k 看直线转动，拖 a 看抛物线开合。
对标粒子先生"拖电阻看电流"的 killer 交互，30 秒讲透。

### 3.1 S1 子系列（初中全体系，生产顺序按可视化锋利度）

- **S1a 函数系列**（先锋）：一次函数 / 二次函数 / 反比例函数
- **S1b 几何系列**：三角形 → 全等 → 轴对称 → 勾股定理 → 平行四边形 → 旋转 → 圆 → 相似
- **S1c 代数系列**：一元一次/二次方程、二元一次方程组、不等式（数轴解集）、整式、分式
- **S1d 统计概率系列**：数据的收集与整理、概率初步（数据可视化天然对口）

呈现上按教材顺序系列化，生产上先锋利后补全。

## 4. 工具迭代路径（与内容并行）

- **v0**：纯 Web 单页工具，只做函数可视化这一个场景，做透。不做导航、不做框架。
- **v1**：知识点导航（按教材章节组织），内容多了得有地方摆。
- **v2**：框架化——可视化组件库 + 知识点 schema，为开源众包和 AI 生成铺路。
- **v3**：一键导出 GIF/演示视频（短视频生产预留）。

**多端（Tauri）**：目标 Web + 桌面端。v0 纯 Web（验证最快；前端写成纯 Web 应用，Tauri 壳随时可套，零成本推迟）→ M3 开源发布时同步出 Tauri 桌面版（离线包，覆盖教室无网场景）。移动端（PWA / Tauri mobile）暂不启动。

顺序原则：先手工做透几个知识点验证模式，再抽象框架，不提前抽象。

## 5. 内容生产管线

统一范式（每个知识点固定三段式）：
1. **概念引入**——一句话说清这是什么
2. **交互探索**——拖参数、看变化，自己动手
3. **例题验证**——一道典型题，当场用上

管线：选题 → 交互设计 → AI/人工开发 → 三层审核 → 发布。

**三层审核**（审核人：yiyi）：
- L1 机器自检：数值正确性（代码验证）、渲染正确性，自动化
- L2 yiyi 审核：数学正确性、表述严谨性、交互是否有误导；初中→大学为舒适区高标准，研究生及以上走研究式审核（查文献、交叉验证，不确定的明确标出）
- L3 真实用户抽检：老师/学生试看，"看懂了吗"是最硬的指标

审核标准文档化（后续形成 REVIEW_GUIDE），AI 生成初稿与众包贡献统一遵循。
S4/S5 的外部教研（众包数学系学生/老师）提前规划，不到时再找人。

## 6. 里程碑（S1）

- **M1**：一次函数可视化上线（Web，可交互：拖 k/b 看图像变化）
- **M2**：二次函数 + 反比例函数（顶点/对称轴/交点标注）
- **M3**：S1a 开源发布 v0.1——GitHub 公开仓库，README（含愿景、演示 GIF）、MIT 协议；同步出 Tauri 桌面版（离线包）
- **M4**：v1 知识点导航（初中数学章节结构）
- **M5**：S2 高中启动（三角函数）

## 7. 风险与红线

1. **教研质量是生死线**：可视化讲错比没有更害人，审核机制不打折。
2. **Scope creep**：S1 只做函数，做到极致再扩；不因为"顺手"提前做几何/高中。
3. **持续投入**：这是长期主义工程，不是一周 v0 的小工具；内容没有"做完"的一天，只有"下一季"。
4. **不碰**：算法可视化、AI 可视化（已明确排除）；英语可视化暂不启动（与 personal-language-agent 保持距离）。

# ADR-002：内容版本号规范（年级.序号）与三级页面收纳

> 日期：2026-10-06 | 状态：已拍板（用户）| 关联：prd-v1 F8、prototype/v1-visual-prototype.html

## 背景

- v0/v1/v2 是**工具迭代版本**（实现层面的 milestone），用户从中看不出内容覆盖到哪里。
- v0 的扁平导航（首页分段选择器切知识点）撑不过 10 个知识点，必须有可扩展的收纳结构。

## 决定：版本双轨

### 内容版本（面向用户）：`{年级}.{序号}`

- 格式如 `初二.1`、`初三.1`、`初三.2`：大版本 = 年级，小版本 = 该年级内知识点的**上线顺序**。
- 年级按人教版实际归属，不按 S1a/S1b 系列：
  - `初二.1` = 一次函数（八下）
  - `初三.1` = 二次函数（九上）
  - `初三.2` = 反比例函数（九下）
- 展示位置：知识点页标题旁版本 badge（12px 蓝底 chip）、年级页列表每行标注。
- 往后自然延伸：`高一.1`、`大一.1`……；小学（S6）为 `小一.1` 起。

### 工具版本（内部）：`vX.Y`

- v0.1 / v0.2 / v1.0…… 只标记实现迭代（视觉重设计、技术升级、框架化），**不出现在 UI**，只在 GitHub release / 更新日志里用。
- 内容新增才推内容版本；纯视觉/性能优化不推内容版本。

## 三级页面收纳

```
首页（按年级：初一 / 初二 / 初三 卡片，显示已上线数）
 └─ 年级页（按系列分组：函数系列 / 几何系列 / …，每行：知识点名 + 版本 badge + 状态）
     └─ 知识点页（面包屑返回：‹ 初三 · 函数系列）
```

- 未上线知识点显示"规划中"，占位不跳转——让用户看到全貌（路线图的存在感）。
- 系列内顺序按教材章节，生产顺序仍按可视化锋利度（roadmap 既定原则不变）。

## 否决的备选

- 继续用 v0/v1/v2 做用户可见版本：用户看不懂 v1.3 是初几的内容，否决。
- 扁平列表 + 搜索：知识点上百后列表不可用，且"按年级"是家长/老师最自然的心智模型，否决。

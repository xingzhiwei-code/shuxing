## 1. 背景与目标

**背景**：v0（S1a 函数系列：一次/二次/反比例）功能验收全部通过（F1–F8，0 P0/P1），
但页面呈现停留在"工程师按 PRD 拼功能"阶段：坐标系像 Matplotlib 默认图、公式是纯文本硬排、
三卡片垂直堆叠模板感强、首页无视觉锚点。功能正确 ≠ 好看，这是两套手艺。

**v1 目标**（一句话）：把 S1a 三个知识点页 + 首页做一次彻底的视觉重设计，
确立「数形视觉语言 v1」，后续 S1b–S6 直接复用，不再返工。

**成功的样子**：用户打开页面的第一反应是"这个数学工具长得好看"，而不是"功能挺全"。
截图发到 GitHub / 老师群里能自己传播。

## 2. 非目标（明确不做）

- ❌ 不新增任何知识点（S1b 几何等一律不进 v1）
- ❌ 不改数学逻辑与数值（曲线算法、标注数值、边界诚实行为零改动，只改 presentation 层）
- ❌ 不改三段式内容结构（概念→交互→例题的顺序与文案不变，只改视觉呈现）
- ❌ 不加后端/登录/用户系统；不做导出 GIF（v3）
- ❌ 不引入重型 UI 框架（手写 CSS + Canvas，保持包体积与 60fps）
- ❌ 试验区整体 Canvas 化后置（见 ADR-004）：v1 保持"Canvas 图形 + HTML UI"混合架构，
  公式/读数/按钮不画进 Canvas；"拖拽顶点"等 Canvas 级交互为 v2 候选

## 3. 设计原则（新增，v1 最高指导）

1. **图表是主角**：坐标系与曲线是页面的视觉中心，其他一切元素为它让路、为它服务。
2. **视觉减法**（iOS 27）：能靠留白和层级表达的，不用线条和色块；网格退到背景，标注只在需要时出现。
3. **数学之美优先**：公式排版、曲线质感、数字对齐——细节处见品味，这是数形区别于"又一个练习 App"的根本。
4. **一页一眼**：任何一屏，用户 3 秒内知道"看哪里、拖哪里"。

## 4. 视觉规范（design tokens，编码 agent 直接照抄）

### 4.1 色彩（语义色，单屏主色 ≤ 3 种）

| token | 浅色 | 深色 | 用途 |
|---|---|---|---|
| `--fn-main` | `#007AFF` | `#0A84FF` | 函数曲线主色 |
| `--fn-accent` | `#34C759` | `#30D158` | 正向语义（上升/k>0/Δ>0） |
| `--fn-warn` | `#FF3B30` | `#FF453A` | 关键标注点（顶点/截距/矩形点） |
| `--text-1/2/3` | `#1C1A16` / `#4A453C` / `#8E8E93` | `#FFFFFF` / `#EBEBF5` / `#98989F` | 三级文字 |
| `--grid` | `#E9E3D3`（弱） | `#2C2C2E`（弱） | 网格线：**弱到刚好能看见** |
| `--axis` | `#8E8E93` | `#98989F` | 坐标轴线 |
| `--card` | `#FFFDF8` | `#1C1C1E` | 卡片底 |
| `--bg` | `#F4F1EA` | `#000000` | 页面底（浅色为暖纸，实验室手账感） |
| `--sep` | `#E8E1D1` | `#38383A` | 分隔线 / 桌面工作台 hairline 边框 |

规则：曲线只用 `--fn-main`；标注点只用 `--fn-warn`；语义文字（上升/下降）用 accent/warn；
网格线透明度以"余光能感知、直视不抢戏"为准。

**边框规则**：手机端卡片无边框（iOS 浮卡）；桌面端工作台面板（目录/实验台/参数/分解）统一 1px `--sep` hairline 边框 + 弱阴影（`0 2px 10px rgba(60,50,30,.05)`），从"浮卡"变为"仪器面板"——这是管理后台感的来源。

### 4.1.1 Entity-color binding（实体色彩绑定，P0 视觉签名）

源自 3Blue1Brown 的核心手法（2026 前沿调研结论）：**同一数学实体，全场同一种颜色**——
公式里的符号、图表上的几何化身、滑杆、标注点、读数，全部绑定同一 hue。
颜色成为语义，不是装饰。

| 实体 | token | 浅色 / 深色 | 绑定位置 |
|---|---|---|---|
| k / a（主参数） | `--fn-main` | `#007AFF` / `#0A84FF` | 公式符号、曲线、滑杆名/填充/数值、k 相关标注 |
| b（一次）/ c（二次） | `--ent-b` | `#FF9500` / `#FF9F0A` | 公式符号、截距点、滑杆 |
| b（二次） | `--ent-t` | `#5AC8FA` / `#64D2FF` | 公式符号、滑杆 |
| 顶点 / 关键点 | `--fn-warn` | `#FF3B30` / `#FF453A` | 顶点标注点 + chip、概念正文中的"顶点" |

约束：单页实体色 ≤ 4 种；不得为装饰引入新 hue；深色模式每种实体色有对应变体。

### 4.2 字阶（iOS 动态字体精神，固定 scale）

- 大标题 34 / 加粗（页面标题，如"二次函数"）
- 副标题 15 / `--text-3`（"y = ax² + bx + c · 拖参数看开口、顶点、对称轴"）
- 卡片标题 20 / 加粗（"交互探索"）
- 正文 16 / `--text-1`（概念引入文案）
- 标注 13 / `--text-2`（引导任务、状态条文字）
- 刻度 11 / `--text-3` / `tabular-nums`（坐标轴数字、滑杆数值）

### 4.3 间距与圆角（4pt 基准）

- 页面边距 16；卡片内边距 20；卡片间距 12；卡片圆角 16（连续圆角观感）
- chip（状态条/小标签）圆角 8，内边距 8/12
- 图表区与滑杆区间距 ≥ 20，给图表呼吸感

### 4.4 公式排版（本次最掉价的单点，P0 级视觉项）

- 全站数学公式统一用 **KaTeX** 渲染（npm 引入，按需加载，体积可接受）
- 行内公式与正文基线对齐；独立公式居中、字号 20
- 变量一律斜体（KaTeX 默认），数字正体——不允许纯文本公式出现在页面上

## 5. 功能需求

### F1 · 图表美学重做（P0）
- 网格：弱化到背景（见 `--grid`），网格线间距自适应（手机端不过密）
- 曲线：线宽 3.5pt，`--fn-main`，线条抗锯齿；**不加模糊阴影**（用户明确要求）；拖动时不做发光反馈
- 坐标轴：`--axis` 细线，箭头简洁；刻度数字 11pt `--text-3`，不与曲线/标注重叠（自动避让或淡化被压住的刻度）
- 标注点：实体色实心圆点 + 白色描边 + 外圈柔光（见 §4.1.1 绑定关系），坐标文字用 chip 样式（圆角 8，半透明底），**不得遮挡曲线关键形态**
- 图内实时公式：图表左上角常驻当前方程（如 `y = 2x + 3`），参数符号按 §4.1.1 着色，随拖动实时更新（Desmos 式 in-figure 标签，不用图例外置 legend）
- 特殊线（对称轴/渐近线）：虚线，`--text-3` 色，标签 11pt 贴线放置
- k 几何意义矩形：半透明 `--fn-main` 填充（10% 透明度）+ 虚线边，面积 chip 实时跟随

### F2 · 页面节奏重构（P0）
打破"三白卡片垂直堆"：
- **交互探索上浮为 hero 区**：图表卡片是页面视觉中心，纵向占比最大，顶部与大标题之间只隔 12pt
- 概念引入收成 hero 下方的紧凑引导条（一句话 + 公式，不再是大卡片）
- 引导任务（"试试把 k 拖到 2"）做成图表下方的横向 chip 组，点一下自动把参数动画过渡到目标值（F7 联动）
- 例题验证保持折叠式，样式与新视觉统一

### F3 · 滑杆重做（P1）
- iOS 原生 UISlider 质感：轨道 4pt 圆角（已填充段 `--fn-main`，未填充段 `--grid` 深色）、
  拇指 28pt 白色 + 柔阴影，拖动时拇指放大 1.15 倍（spring 回弹）
- 参数名（k/b/a）用 15pt 加粗斜体（数学变量感），数值 15pt `tabular-nums` 右对齐
- 滑杆行纵向间距 16pt，不再是"设置页面"既视感

### F4 · 状态条 chip 化（P1）
- "↗ 上升 · k>0"这类状态提示统一为 chip：圆角 8、语义色 12% 底 + 语义色文字、
  图标（↗/↘/→）与文字基线对齐
- 边界诚实提示（a=0 退化）用 `--fn-warn` 色 chip，文案不变

### F5 · 首页重做（P0）
- 顶部 hero：一个**实时动画的函数曲线**（如二次函数顶点漂移的循环动画，Canvas 绘制，
  60fps，尊重 `prefers-reduced-motion` 则静止显示首帧）+ 大标题"数形" + 一句话 slogan
- 三个知识点入口改为大卡片：每卡配**静态曲线缩略图**（Canvas 快照或 SVG，一次/二次/反比例各一），
  标题 + 公式（KaTeX 行内）+ "进入 →"
- 底部保留 roadmap 指向（"更多系列规划中"），样式弱化

### F6 · Dark Mode 正式实现（P0）
- v0 只是"预留"，v1 正式做完：全页面（含 Canvas 网格/曲线/标注/chip）跟随系统切换
- 切换入口保留右上角 🌙，切换时用 0.3s 淡入淡出（非线性跳变）
- 验收：浅色/深色各截全套页面对比走查（见 AC5）

### F7 · 动效 polish（P1）
- 参数变化时曲线做 **morph 过渡**（120ms，spring 曲线），而不是硬跳帧——"拖"的跟手感保留，
  "点 chip 自动设值"时用过渡动画
- 页面进入：图表卡片 0.25s 上浮淡入（spring），其他元素依次 30ms stagger
- 全部动效遵循 `prefers-reduced-motion`：开启动效全部关闭，数值直接跳变
- **曲线本身不加模糊阴影**（用户明确要求）：质感靠线宽 3pt + 圆角端点，不靠发光

### F8 · 页面收纳与内容版本号（P0，见 ADR-002、ADR-003）
- 三级导航 v2：首页（4 张分支卡片：函数与分析 / 几何与空间 / 代数与方程 / 概率与统计，
  整幅 canvas artwork + 大标题压字，App Store Today 式）→ 分支页（学习路径时间线，
  初中→高中→大学→前沿，节点：已上线实心分支色圆点 / 未上线灰色空心）→ 知识点页；
  每级面包屑返回（如"‹ 函数与分析"）
- 内容版本号 `{年级}.{序号}`：`初二.1` 一次函数、`初三.1` 二次函数、`初三.2` 反比例函数；
  知识点页标题旁版本 badge（12px 蓝底 chip），路径节点行标注版本 + 学段徽标（初中/高中/大学）
- 未上线知识点显示"规划中"占位，不跳转
- 工具版本 vX.Y 不出现在 UI

### F9 · 响应式布局（P1，手机优先、桌面展开）
使用优先级：手机 > 桌面 > Web。手机是第一设计目标，桌面是自然展开，不做第三套设计。

- 断点唯一：`1024px`。`<1024px` 单列（即本 PRD 前述全部规范）；`≥1024px` 展开。
- 桌面展开规则：
  - 页面 `max-width: 1180px`，导航同宽
  - 首页：分支卡片 2×2 网格，卡片高 200px；hero 高 340px，标题 56px
  - 函数页：图表 + 控制双栏（约 8:5），控制栏 `position: sticky`；图表 `aspect-ratio: 16/10`；概念/例题全宽在下
  - 分支页：路径时间线限宽 760px
- 禁止：桌面端把同一内容做成另一套信息架构；禁止横向滚动条

#### F9b · 桌面函数工作台 workbench（P0，≥1024px）
桌面端函数页不是放大版手机页，而是三栏工作台（左 300px｜中自适应｜右 330px，左右栏 sticky）：

- W1 参数控制（左）：语义滑杆 + 每条滑杆下的语义预告行（如 `k=3 · 每向右 1 格，向上 3 格`）+ 状态 chip + 试试/演示
- W2 图像实验台（中）：图表 + 图内公式 + 关键点点击放大窗（大字读数卡，点空白处关闭）
- W3 参数分解（右）：参数分解表（参数名/当前值/语义三列，随拖动实时更新）+ 探究三步（编号步骤）+ 铁律（红色警示条）
- 手机端（<1024px）保持单列，工作台面板按"图表 → 参数控制 → 参数分解 → 概念 → 例题"依次堆叠

#### F9c · 课程目录常驻（P0，≥1024px，仅桌面）
- 桌面端函数页左侧常驻课程目录（264px，sticky）：分支名 + 学习路径列表（已上线实心分支色点/规划中灰色空心点 + 版本号/学段）
- 点已上线知识点直接在右侧教学区切换（重播入场动画），无需返回分支页；当前项高亮
- 手机端目录隐藏，保留现有面包屑返回

### F10 · 动态层 motion layer（P0，对标 3Blue1Brown 的电影感 × 可交互）
动态为交互服务，不做纯装饰动画。零动画库依赖：rAF + CSS transition + WAAPI。

- M1 三段式入场：进函数页 1100ms 内依次生长——坐标轴（0–330ms）→ 网格（90–420ms）→ 曲线从左向右生长（330–990ms）→ 标注点/图内公式（790–1100ms）；smoothstep 缓动；`prefers-reduced-motion` 下跳过
- M2 镜头微动：页面切换时 0.985→1 轻微推近 + 淡入，380ms `cubic-bezier(.2,.7,.2,1)`，替代硬切
- M3 演参数：▶ 演示按钮，第一参数（k/a）从 min→max 自动播放，1×=4.5s，速度 1×/2× 可切；播放中按钮变为"⏸ 停止"并高亮；拖滑杆/点 chip/切页即停
- M4 焦点高亮-变灰：操作某参数时，其他参数的滑杆行、公式符号、归属标注点降至 35% 透明度；松手 700ms 后恢复
- 约束：禁止引入 Three.js / D3 / GSAP 等动画库（3D 是化学的解，不是数学函数的解；参数函数可视化与 D3 的数据抽象不对口；现有 rAF + easing 已覆盖需求）

#### F9d · 桌面应用框 application frame（P0，≥1024px，仅桌面）
对标"像软件不像网页"：

- A1 顶栏应用化：品牌 +「自由探索」+ 日期 + 实时时钟（秒级）+「本地运行」状态点
  （工具版本号不进 UI，见 ADR-002）；手机端仅保留品牌

# 数形 (shuxing) · 项目宪法

> 2026-10-06 用户拍板。所有产品决策、PRD、代码实现与内容生产都必须符合以下宪法。
> 宪法修改需用户明确批准。

---

1. **数学正确性是底线**——讲错比没有更害人。这是第零条，凌驾于一切之上。
2. **用户体验最高优先级**——UI 和交互是除数学正确性之外最高优先级。不好用、不好看的可视化没有资格谈教育。
3. **诚实**——不为好看牺牲准确，不伪造"看懂了"。可视化必须忠实于数学本质，不简化到失真，不为了演示效果编造结论。
4. **先给一个人用爽，再谈体系**——S1 先锋季先验证模式，跑通"做出来 → 有人用 → 看懂了"再扩系列。不为了"全体系"的愿景提前铺摊子。
5. **简单可演进**——v0 不做框架，先把一个场景做透；抽象只在模式验证后发生。
6. **开源开放**——MIT 协议，拥抱众包。代码、内容范式、审核标准全部公开。

## 产品红线

- 任何未经 L2 审核（yiyi 教研审核）的数学内容不得发布。
- 不引入算法可视化、AI 可视化、英语可视化（已明确排除的方向）。
- 不收集学生个人信息；桌面端离线优先，不强制联网。

## 附：UI / 交互 / 动画风格标准（2026-10-06 用户拍板增补）

**标杆澄清**：此处"Apple 级"特指 **iOS 系统级交互**（非 macOS / watchOS），
即 iPhone 系统应用（设置、照片、信息）那种"跟手、有弹性、收放自如"的感觉。

**核心三词**：跟手、弹性、克制。

### 可验收标准

1. **弹簧物理**：所有过渡动画使用 spring（阻尼弹簧）或 iOS 式 easeInOut；禁止线性动画和生硬跳变。
2. **跟手**：拖参数滑杆时图像实时跟随（目标 60fps），无肉眼可感知的延迟；动画可被手势打断。
3. **边界弹性**：滑到 min/max 时有回弹反馈，不生硬截断。
4. **按压缩放**：可交互元素 active 态 0.97 缩放，100ms 内给出视觉反馈。
5. **浮层**：sheet 式浮层，移动端可下滑关闭。
6. **克制配色**：单屏主色 ≤ 3 种，iOS 系统色板优先。
7. **统一圆角**：卡片 10–14px，全站一致。
8. **排版**：-apple-system 字体栈优先，数字用 tabular-nums，正文字体不小于 14px。
9. **Dark Mode**：v1 支持，v0 架构预留。
10. **无障碍**：跟随系统"减少动态效果"设置。

### 诚实条款

iOS 级是方向，v0 先做到"跟手、流畅、一致"三件套；Web 实现以"感觉对"为准，
不逐像素复刻；iOS 体感验收由 yiyi 按本标准走查，达不到的如实记入 audit 报告，不硬凑。

### iOS 27 增补（2026-10-06 用户拍板：融入 Liquid Glass，取舍由 yiyi 判断）

- **Liquid Glass（液态玻璃）**：只用在浮层类——导航栏、sheet、悬浮工具条；
  不用在大面积背景和卡片内容区（可读性 + 性能）。
  配方：`blur(24px) saturate(1.8)` + 0.5px 高光描边 + 柔投影 + 内高光。
- **视觉减法**：能用间距/底色分层的，不用轮廓线；图标圆角化。
- **降级**：跟随系统"减少透明度"（`prefers-reduced-transparency`）自动降级为实色；
  backdrop-filter 只出现在浮层上，避免低端机掉帧。
- **不融入**：Siri AI、锁屏/小组件/闹钟/音量/智能粘贴等系统级功能（Web 够不着）；
  不做系统级的"透明度调节滑块"。

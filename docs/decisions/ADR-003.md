# ADR-003：导航信息架构 v2 —— 按数学分支（替代 ADR-002 的年级导航）

> 日期：2026-10-06 | 状态：已拍板（用户）| 替代：ADR-002 中的"三级页面收纳"部分（版本号 `年级.序号` 保留，继续有效）

## 背景

ADR-002 定了"首页按年级（初一/初二/初三）→ 年级页按系列 → 知识点页"。
用户在看到可交互原型后提出两点：
1. 数形要搭的是**一整个数学体系**（初中→前沿），按年级切分是"教材视角"不是"数学视角"—— S4/S5（研究生/前沿）根本无法归入年级。
2. 年级卡片（渐变徽标+文字+箭头）像设置列表，离 iOS 系统级高级感差得远。

## 决定：顶层按数学分支，分支内是学习路径

```
首页（4 张分支卡片：整幅 artwork + 大标题压字）
 └─ 分支页（学习路径时间线：初中 → 高中 → 大学 → 前沿）
     └─ 知识点页（面包屑返回：‹ 函数与分析）
```

四大分支（与 knowledge-map 的 S1a–S1d 对应，天然向 S2–S5 延伸）：
| 分支 | EN | 身份色 | 路径起点 |
|---|---|---|---|
| 函数与分析 | FUNCTIONS & ANALYSIS | 蓝 `#007AFF` | 一次函数（初二.1）→ … → 导数与微分（大学） |
| 几何与空间 | GEOMETRY & SPACE | 橙 `#FF9500` | 三角形（初中）→ … → 微分几何（大学+） |
| 代数与方程 | ALGEBRA | 绿 `#34C759` | 有理数（初中）→ … → 抽象代数（大学+） |
| 概率与统计 | PROBABILITY & STATISTICS | 红 `#FF3B30` | 数据收集（初中）→ … → 数理统计（大学） |

- **年级退化为元数据**：不再作为导航层级；保留两处——知识点行的"学段"徽标（初中/高中/大学）、版本号 `年级.序号`（如初三.1）。
- **分支卡片设计语言**（iOS App Store Today 式）：整幅 canvas 生成的线条 artwork（暗底 + 分支 hue 细线构成，各分支母题不同）+ 底部渐隐罩 + EN 眉题 + 25px 中文大标题 + "N 个知识点已上线 · 路径 初中 → 前沿"。按压缩放 0.97。
- **路径时间线**：垂直线 + 节点圆点（已上线 = 分支色实心 + 光晕环，未上线 = 灰色空心）；节点卡片含知识点名、版本 badge、学段徽标、状态（› / 规划中）。

## 为什么是分支而不是学段（S1/S2…）

- "数学体系"的心智模型是分支（3Blue1Brown、Khan Academy、Brilliant 全部按分支/系列组织），不是学段。
- 生产顺序（roadmap：先锋利后补全）天然按分支推进，导航与生产同构。
- 教材视角（年级/学段）只解决"找课"问题，分支视角同时解决"找课"和"看体系"两个问题——后者是数形的差异化。

## 否决的备选

- 年级三级收纳（ADR-002 原案）：用户亲眼看过原型后否决。
- 学段（初中/高中/大学）做顶层：比年级好一点，但依然是"补习班"视角，不是"数学宇宙"视角，否决。
- 双入口（分支+学段并存）：复杂度翻倍，v1 不做；若真实用户反馈强烈再考虑。
